## 👤 01 // Sobre mí

Soy **Hugo Carrasco Castro**, estudiante de segundo
curso del Ciclo Formativo de Grado Superior de
Desarrollo de Aplicaciones Multiplataforma.

Mi trayectoria en la informática comenzó con Sistemas
Microinformáticos y Redes, donde descubrí diferentes
ámbitos de la tecnología, desde el funcionamiento
del hardware hasta la administración de sistemas
y redes.

Actualmente estoy orientando mi formación hacia
el desarrollo de software, trabajando con diferentes
lenguajes de programación, frameworks, bases de datos
y herramientas de desarrollo.

Me considero una persona responsable, curiosa y
con ganas de seguir aprendiendo. Me gusta entender
cómo funcionan las cosas, resolver problemas y
buscar maneras de mejorar lo que ya existe.

Mi objetivo es completar mi formación en DAM,
continuar con DAW y adquirir experiencia profesional
en el sector del desarrollo de software.

puedan evolucionar con el tiempo.

## 💼 04 // Experiencia práctica

### Mantenimiento y modernización de software

Actualmente estoy complementando mi formación
académica con prácticas profesionales, trabajando
en el análisis y modernización de un proyecto
desarrollado con Unity.

El proyecto fue creado originalmente con una
versión de Unity de 2018 y está siendo adaptado
a una versión de Unity 6.

### Principales tareas

| Área | Actividades |
|---|---|
| Auditoría | Inventario y clasificación de recursos |
| Análisis | Identificación de dependencias y referencias |
| Programación | Revisión y adaptación de scripts C# |
| Migración | Compatibilidad entre versiones de Unity |
| Depuración | Investigación de errores de compilación |
| Mantenimiento | Evaluación de componentes obsoletos |
| Documentación | Registro de cambios y evidencias técnicas |

### Conocimientos que estoy desarrollando

- Mantenimiento de código heredado.
- Comprensión de proyectos existentes.
- Gestión de dependencias.
- Análisis del impacto de los cambios.
- Compatibilidad entre versiones.
- Resolución de problemas técnicos.
- Organización de recursos.
- Documentación y trazabilidad.

Esta experiencia me está permitiendo comprender
que el desarrollo de software no consiste
únicamente en crear aplicaciones desde cero,
sino también en mantenerlas, comprenderlas
y adaptarlas a nuevas necesidades.
